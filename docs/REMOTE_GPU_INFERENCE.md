# 按需远端 OCR 与向量推理

业务队列、数据库和本机 API 地址保持原位置。网关可通过多个 SSH 隧道把 OCR 和向量请求调度到 GPU 节点；文本生成的云端路由保持独立。节点只运行轻量 CPU 守护，收到实际请求后加载模型，最后一个请求结束 120 秒后释放模型进程和显存。

## 配置与部署

- 本机设置 `gateway.remote_pool_config` 或 `FINAGENT_REMOTE_POOL_CONFIG`，指向私有的节点池 JSON。格式参考 `config/inference-pool.example.json`。未设置时保留原本机模式。
- 节点配置参考 `config/inference-node.example.json`，修改模型路径、运行环境路径、端口和内存预算。生产配置、SSH 别名及随机令牌不得提交到 Git。
- 每台节点使用独立令牌文件，权限设为 `0600`，在本机对应配置中放置同一令牌。节点守护与 vLLM 后端均校验认证，令牌通过环境或内存传递，不进入启动参数。
- 将 `node_daemon.py`、`gpu_allocator.py`、`model_lifecycle.py`、`inference_stream.py` 放进节点 runtime。使用独立 Python 3.12 环境及 `services/model_gateway/requirements-node.txt`，不要升级已有训练环境。
- 复制两份模型并逐文件核对 SHA-256；保持模型版本、分词器、向量维度及 pooling 参数一致。模型设置为离线加载。
- 用户服务示例位于 `services/model_gateway/examples/`。节点 API 绑定 `127.0.0.1:18082`，模型后端绑定回环端口；本机通过不同的本地 SSH 转发端口访问两台节点。
- 启用节点用户服务及本机隧道用户服务。隧道自动重连，并在远端登录时确保节点服务启动，因此没有 linger 的节点也能随本机重连恢复服务。没有开放新的公网或 LAN 监听端口。

## 调度规则

每次请求优先复用已经就绪的模型；有多份就绪模型时优先请求较少的一份。冷启动选择具备足够未预留显存的节点。节点重新检查实时 GPU 状态，在锁内预留内存后启动，避免本守护的并发请求重复占用同一份剩余容量。

存在其他计算进程的 GPU 不参与新分配，即使显示仍有很多空闲显存。没有本守护预留且利用率超过阈值的 GPU 同样跳过。本守护自己的 OCR 和 embedding 可在一张容量充足的 GPU 上共存。配置中的模型预算包含运行余量，GPU 额外保留 1 GiB。vLLM 0.21 使用即时查询的设备编号启动，调度记录保留 UUID。

独立进程无法替代整机 Slurm 等统一调度；其他用户在检查后同时启动任务仍可能产生竞争。发生启动失败时只清理本守护创建的进程，尝试另一节点，不终止其他用户的任务。默认没有本机 GPU 回退。

节点无法连接或明确返回启动/容量失败时，网关最多尝试其他可用节点一次；已经返回的响应流不会自动重放。两台均无容量时返回带 `Retry-After` 和 `x-finagent-retryable: capacity` 的 503。OCR/向量客户端等待此明确容量信号，不把它计入内容失败次数；向量任务仍遵守原有时间预算及停止请求。

## 切换与验收

先验证两台节点上的合成 OCR 数值、向量维度及与原向量的相似性，确认模型文件一致。再验证忙碌设备避让、隧道断开切换、自动重连、流式请求期间不卸载，以及空闲后进程和显存确实消失。`make test-gateway` 不启动真实 GPU，真实验收需要独立执行并保存记录。

切换前暂停原推理消费者并保存队列租约、日志和页缓存。旧版 OCR worker 若不支持优雅退出，只能把该服务自身未完成的准确队列 ID 与 started_at 租约恢复为 pending，不能批量重置其他任务。向量消费者在批次边界退出并释放自己的租约。网关切换后原地址、密钥和向量模型标识不变，再恢复消费者。

查询本机 `/internal/models/status` 可查看 `remote_on_demand`、各节点模型状态、GPU UUID、预留容量及不可用原因；该查询不会加载模型。CPU 守护保持运行是预期行为，不代表 GPU 模型常驻。持续 OCR 或向量补全期间模型不会空闲卸载。

回滚时先停消费者并保存精确续传状态，取消 `FINAGENT_REMOTE_POOL_CONFIG`，重启本机网关并验证原本机模型，再恢复消费者。远端模型会在闲置窗口后自动释放；不要启动已淘汰的其他 embedding 服务。旧 `validate_on_demand.py` 是本机专用验收，远端部署应使用节点状态和本次部署的远端验收记录。
