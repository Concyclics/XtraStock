# 持续候选池与历史挖掘配置

配置入口为 `config/research_pool.json`。调度每次启动脚本时重新读取，无需为了修改这些参数重启常驻服务。

## 研究名单如何维护

- 每天北京时间 08:40、22:40 随原研究流水线发现、评分和记录候选。来源为完整研究快照，公告先按公司限额，再执行总量限制。
- 活跃探索空间 300 家，其中持续跟踪 80 家，80 家中包含重点层 20 家。其余 220 家处于探索层。
- 每周首个成功刷新执行重排。默认重点层与观察层共用 4 次替换预算，挑战者至少高 5 分，旧成员至少已跟踪 7 天。数据失效退出和空缺补充另记；这不是实际持仓规则。
- 每月首轮复核长期论点，保存上次论点、变更与下次复核日期。退出成员进入默认 30 天冷却，之后归档，历史版本保留。
- 重点层每行业最多 4 家。缺失行业的公司共用一个限额桶。行业来自证券主数据，缺失时使用两年内最近机构研报分类，来源与未知数均写入日志。

长期分使用已核实、报告期未超前且最近 210 天内的营收/归母净利润同比与同口径现金流利润比；短期分来自当前快照的量价/风险因子分位数。权重为 65% / 35%，缺项不把权重重新分配给另一项。重点层还要求正利润、有效短期分及基本流动性。无方向公告数量不加看涨分；分类中的图谱关联只作调查线索。分数不是收益率或上涨概率。

到期预测误差触发复核时，短期综合排序降权。缺少成熟结果视为待观察，不当作表现好或差。

## 挖掘要求的前缀时长

`mining.min_train_sessions` 是**最短训练前缀**，不是固定滚动窗口。样本充足时会使用更长的扩展训练窗口。

| 配置 | 默认 | 可调范围/含义 |
| --- | ---: | --- |
| `min_train_sessions` | 126 | 60–2000 个有效交易日期 |
| `test_sessions` | 40 | 20–252；实际不小于预测期的两倍 |
| `folds` | 2 | 1–5 个测试折 |
| `history_days` | 1500 | 回溯 365–1800 个自然日 |
| `horizons` | `[5,20]` | 支持 5、20、60 个交易日 |
| `max_stocks` | 40 | 本轮挖掘最多 40 家 |
| `min_assets_per_date` | 8 | 每个有效日期至少有这些公司的完整样本 |
| `max_candidates` | 16 | 1–25 个价格因子表达式 |

所需有效日期数为：

```
最短训练前缀 + 折数 × (max(测试期, 2 × 预测期) + 预测期)
```

原严格路径默认是 `500 + 3 × (80 + 20) = 800`。现在的历史重构研究配置，5 日任务最低 216 个日期，20 日最低 246 个日期。同一天增加股票数不能增加日期数；缺数据不填充，也不自动降低配置门槛。

在应用根目录查看当前计划，不训练、不写入研究结果：

```bash
.venv/bin/python scripts/analytics/run_weekly_factor_research.py --mode configured --dry-run
```

单次试算更短前缀，例如 90 日训练、20 日测试、两折、5 日预测（需要 140 个日期）：

```bash
.venv/bin/python scripts/analytics/run_weekly_factor_research.py \
  --mode configured --min-train-sessions 90 --test-days 20 --folds 2 \
  --horizon 5 --dry-run
```

要让定时任务长期采用新值，修改 JSON；命令行参数只覆盖本次运行。去掉 `--dry-run` 会实际运行。每周日北京时间 06:30 后随机延迟最多 5 分钟执行，结果写入独立的历史重构研究表。相同输入复用已有结果。

`--mode strict` 保留严格 PIT 路径；`--mode reconstruction` 使用历史重构；`--mode configured` 读取 JSON。严格路径不会因为重构样本充足而假定历史 PIT 数据已经存在。

## 预测、审核与交付

每日学习从当前候选池按排名取 20 家，冻结 5/20 日预测，随后对实际到期结果和源数据修订追加复盘。候选轮换后，旧公司的未结算预测继续处理。训练输入按 5 家串行读取，单条 SQL 最多 25 秒，总读取预算 120 秒；超过 40 家的旧预测使用额外的短持有期批次，共享总预算。

历史挖掘只在训练段选择表达式和方向，在隔离后的测试段评价。当前价格模型不包含历史财务/图谱回填；财务与图谱用于当下候选筛选。按当前候选名单回看历史存在选择偏差，测试价差未含完整交易成本，不能直接算作可执行策略收益。

QQ 使用 `finance_research_intelligence(scope="pool")` 查询汇总、成员、月度论点、冻结预测和挖掘配置。概览使用 `limit=2..5`，指定公司用 `stock_codes`。日报保留原 AI 硬件观察池，另增“长期候选池更新”，至少保留两家公司明细的证据。

新表均为追加记录；应用无修改/删除权限，Agent 只有读取权限。研究资格和生产资格分开记录，未通过模型检验的数值不会作为合格收益预测展示。此次升级不执行交易，也不自动把研究因子升级为生产因子。
